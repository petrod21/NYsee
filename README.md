# Nysee

Build an app for New York City where you enter your trip length and hotel location and pick from the top 50 attractions on trip advisor. Then build a daily itinerary based on grouped sites and show subway lines and walking directions between each stop

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://nysee.lovable.app
